# pymongo-api

## Как запустить

Запускаем mongodb и приложение

```shell
docker compose up -d
```

Дождитесь поднятия всех контейнеров и автоматической инициализации шардирования. Может занять пару минут. Этапы инициализации можно увидить в логах контейнера sharding-init.

Как только контейнер pymongo_api будет поднят можно заполнить его данными

```shell
cd .\api_app\
python test_sharding.py
```

## Как проверить

Откройте в браузере http://localhost:8080
В JSON ответе есть ключ "shards_detail" в нём вы увидите детальную информацию о шардах в том числе их наполнение


### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080

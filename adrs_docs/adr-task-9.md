# ADR: Настройка чтения с реплик и консистентность

**Контекст:** Определение стратегии чтения для коллекций `products`, `orders`, `carts`


## 1. Коллекция `products`

| Операция | Куда читать | Задержка | Обоснование |
|----------|-------------|----------|-------------|
| Просмотр/поиск товаров | `secondaryPreferred` | до 5-10 сек | Цена и описание меняются редко, задержка 5-10 сек незаметна |
| Проверка остатков | **`primary`** | 0 сек | **Критично**. Устаревший остаток -> продажа товара, которого нет -> негативный опыт клиента |

## 2. Коллекция `orders`

| Операция | Куда читать | Задержка | Обоснование |
|----------|-------------|----------|-------------|
| История заказов | `secondaryPreferred` | до 2 сек | Пользователь не заметит задержку 1-2 сек |
| Статус заказа | **`primary`** | <1 сек | **Критично**. Пользователь ждёт актуальный статус (оплачен/отправлен). Устаревший статус -> тревога пользователя |

## 3. Коллекция `carts`

| Операция | Куда читать | Задержка | Обоснование |
|----------|-------------|----------|-------------|
| Отображение корзины | `secondaryPreferred` | до 2 сек | Только просмотр, задержка 1-2 сек допустима |
| Проверка корзины перед заказом | **`primary`** | 0 сек | **Критично**. Ошибка в корзине -> неправильная сумма заказа |
